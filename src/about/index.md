# 運営者情報

このサイトは、親の家・実家の片付けに向き合う人のために、片付けの段取り、業者の種類と選び方、費用の決まり方をまとめています。

特定の業者をおすすめすることよりも、依頼先を自分で比べて選べるようになることを目的にしています。相続・税金・登記など法律にかかわる判断は扱わず、公的な窓口や専門家への相談をおすすめしています。

記事の執筆・構成の一部にAIツールを活用しています。公開前の内容確認は運営者が行っています。

## 編集方針

- **公的な情報を確認して書きます。** 法律や制度に触れるときは、消費者庁・国民生活センター・環境省・法務局・自治体などの公開情報を確認し、記事から案内しています
- **体験談を作りません。** 実際に依頼していない業者を「頼んでみた」と書くことはしません
- **特定の業者を一番とは書きません。** 依頼先は2〜3社の見積もりを比べることをおすすめしています
- **お金のかからない方法も紹介します。** 自治体の粗大ごみ回収など、業者に頼まずにできる方法も公平に扱います
- **法律・税金の判断は扱いません。** 相続・登記・税金については概要と相談先の案内にとどめます
- **内容を見直します。** 制度の変更や読者からのご指摘があれば、記事を更新します
