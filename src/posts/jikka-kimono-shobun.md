実家の和ダンスを開けると、たとう紙に包まれた着物や帯がたくさん出てくることがあります。母や祖母が大切にしていた物だと思うと、簡単には手放せません。一方で、着る人がいないまま置いておくと、湿気やカビで傷んでしまうこともあります。

先に結論をまとめると、**着物は「家族で残したい物」を先に選び、残りを状態ごとに分けてから、着物を専門に扱う買取に見てもらう**順番が進めやすい方法です。すべてを一度に決めなくても、残す物と手放す物を分けるところから始めれば十分です。

## 着物の行き先は大きく4つ

| 行き先 | 向いている着物 | 気をつけたいこと |
|---|---|---|
| 家族・親戚に譲る | 思い出の深い物、誰かが着る予定のある物 | 先に希望を聞かないと、後から「欲しかった」となりやすい |
| 仕立て直し・リメイク | 寸法が合わない物、小物や洋服に作り替えたい物 | 仕立て直しの費用がかかる。依頼先に見積もりを取る |
| 買取に出す | 証紙のある物、状態のよい物、帯や和装小物 | 値段がつかない物もある。複数の店で比べる |
| 処分する | 傷みが大きく、残す・売る予定のない物 | 出し方は自治体ごとに違う。資源回収の対象になる場合もある |

ここで大切なのは、**家族で残したい物を先に選ぶ**ことです。買取に出してから「あの訪問着は残したかった」と気づいても、取り戻すことはできません。きょうだいや親戚がいる場合は、写真を撮って共有し、希望を聞いてから次に進みましょう。

## 買取に出す前の仕分け

着物は数が多くなりがちです。次のように分けておくと、査定のときに話が早く進みます。

| 分け方 | 目安 | 一緒にそろえたい物 |
|---|---|---|
| 証紙・作家名がある物 | 産地や織元、作家を示す紙が付いている | 証紙、共布(ともぎれ)、たとう紙 |
| 状態のよい訪問着・留袖・紬など | 目立つシミやカビ、においがない | たとう紙に入れたまま |
| 帯・帯締め・帯揚げ・和装小物 | 着物と別に値段がつくこともある | まとめて袋に入れる |
| シミ・カビ・においがある物 | 状態によっては値段がつきにくい | 無理に洗わず、そのまま |
| 喪服・浴衣・ウールや化繊の着物 | 値段がつきにくいことがある | 買取できるかを事前に聞く |

**証紙は着物の価値を伝える手がかりになる**ため、見つけたら捨てずに、どの着物の物か分かるように一緒にしておきましょう。また、シミやにおいを自分で落とそうとすると、生地を傷めることがあります。手入れはせず、そのままの状態で見てもらうのが無難です。

## 出張買取と宅配買取、どちらを使うか

着物の量が多い場合や、重い桐ダンスごと見てほしい場合は出張買取、数枚だけなら宅配買取が向いています。それぞれの違いは[実家の片付けで売れる物]({{ '/posts/jikka-katazuke-ureru-mono/' | url }})にまとめています。

自宅に来てもらう出張買取(訪問購入)には、特定商取引法によるルールがあります。業者は勧誘の前に名前や目的を伝える必要があり、契約後は書面を受け取ってから一定の期間、クーリング・オフができます。対象や条件は、消費者庁の[特定商取引法ガイド](https://www.no-trouble.caa.go.jp/)で確認してください。また、[国民生活センター](https://www.kokusen.go.jp/)は、着物の買取をきっかけに、売るつもりのない貴金属まで求められるといった相談について注意を呼びかけています。

### 査定の電話や当日に聞いておきたい質問

- 査定料・出張料・キャンセル料はかかりますか
- 帯や和装小物、喪服、浴衣も見てもらえますか
- 値段がつかなかった着物は、持ち帰ってもらえますか(引き取りは有料ですか)
- 査定額の内訳(どの着物にいくらつけたか)を教えてもらえますか
- その場で決めずに、家族と相談してから返事をしてもよいですか

## 残すと決めた着物の保管

残す着物は、湿気と虫から守ることが大切です。年に1〜2回、晴れて乾燥した日に風を通す「虫干し」をすると、カビやにおいを防ぎやすくなります。実家を手放すなどで置き場所がなくなる場合は、空調のある保管サービスを使う方法もあります([形見・家具の保管先の選び方]({{ '/posts/katami-hokan-trunk-room/' | url }}))。

## 着物を片付ける段取りの例

| 段階 | やること |
|---|---|
| 1. 全部出す | タンスや押し入れから出し、だいたいの枚数を数える |
| 2. 写真を撮る | 1枚ずつ広げなくてよいので、柄が分かる写真を残す |
| 3. 家族の希望を聞く | 写真を共有し、残したい物を先に選んでもらう |
| 4. 仕分ける | 上の表のとおり、証紙の有無と状態で分ける |
| 5. 査定に出す | 2社以上に見てもらい、内訳を比べる |
| 6. 残りを決める | 値段がつかない物は、譲る・リメイク・処分から選ぶ |

## 依頼する前に確認したいこと

着物の買取を頼む前に、次の点を確認しておくと安心です。

- 買取店が古物商の許可を持っているか(ホームページで許可番号を確認できることが多い)
- 査定料・出張料・キャンセル料の有無
- 家族で残したい着物を先に取り分けたか
- 査定してほしい物だけを用意し、ほかの物(貴金属など)は見せない準備ができているか
- 相続の手続き中の場合、売ってよいか家族で合意できているか(相続放棄を考えている場合は、売る前に専門家へ相談する)

## よくある質問

### Q. 古い着物でも値段はつきますか？

古さだけで決まるわけではなく、素材、状態、証紙の有無、作家物かどうかなどで変わります。一方で、シミやカビが目立つ物、喪服や浴衣などは値段がつきにくいことがあります。迷う物は処分の前に一度査定を受け、値段がつかなければ次の行き先を考える順番にすると後悔が少なくなります。

### Q. 着物を燃えるごみに出してもよいですか？

自治体によって、可燃ごみとして出せる場合や、古着・古布の資源回収の対象になる場合があります。出し方は実家のある市区町村のホームページやごみの案内で確認してください。

### Q. 母の着物を手放すことに気が引けます。

すべてを手放す必要はありません。思い出の深い1〜2枚を残す、帯や端切れで小物を作るなど、形を変えて残す方法もあります。気持ちの整理がつかない物は、期限を決めて保管し、あらためて考えるのもひとつの方法です。

## まとめ

実家の着物は、家族で残したい物を先に選び、証紙の有無と状態で仕分けてから、専門の買取に見てもらうと進めやすくなります。値段がつかない物も、譲る・仕立て直す・処分するなど行き先はあります。着物以外も含めた片付けの全体の流れは、[実家の片付けは何から始める？]({{ '/posts/jikka-katazuke-nanikara/' | url }})を参考にしてください。
