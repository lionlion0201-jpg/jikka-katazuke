親が施設に入った、亡くなったなどの理由で、実家に住む人がいなくなることがあります。売るか残すかをすぐに決められないまま、「たまに様子を見に行けばいいだろう」と思っているうちに、行く間隔が空いてしまうことも少なくありません。

先に結論をまとめると、**空き家の管理は「換気・通水・家の点検・郵便・庭・戸締まり」の6つに分けて、誰がどのくらいの間隔で見るかを家族で決めておく**と続けやすくなります。通えない場合は、親戚や近所の人、空き家の管理サービスに頼る方法もあります。あわせて、いつまで管理を続けて、いつ家の行き先を決めるかの目安も決めておきましょう。

この記事は管理の段取りの整理を目的にしています。空き家に関する制度や税金の扱いは、自治体の窓口や税務署、専門家に確認してください。

## 住む人のいない家で起こりやすいこと

| 起こりやすいこと | 主な原因 | 見回りで防げること |
|---|---|---|
| カビ・湿気・におい | 窓を閉め切って空気が動かない | 窓や押し入れを開けて風を通す |
| 下水のにおい・虫 | 排水口の水がなくなる | 蛇口から水を流し、トイレを流す |
| 雨漏りや傷みに気づかない | 人の目が入らない | 天井や壁のしみ、床のたわみを見る |
| 郵便物やチラシがたまる | 受け取る人がいない | 回収する、転送の手続きをする |
| 庭木や草が伸びて隣にはみ出す | 手入れをする人がいない | 伸びた枝や草を確認し、手入れを手配する |
| 留守が外から分かる | 雨戸が閉めっぱなし、郵便受けがいっぱい | 郵便を片付け、戸締まりを確かめる |

住む人がいない家は、人が暮らしている家に比べて傷みに気づくのが遅れやすくなります。見回りの目的は、傷みを「なくす」ことよりも、**早く気づいて手を打てるようにすること**だと考えると、無理なく続けられます。

## 1回の見回りでやることのチェック表

| 項目 | やること |
|---|---|
| 換気 | すべての部屋の窓、押し入れ・クローゼットの戸を開けて風を通す |
| 通水 | 台所・洗面所・お風呂の蛇口から水を流し、トイレを流す |
| 室内の点検 | 天井や壁のしみ、カビ、床のきしみ、虫やネズミの跡がないか見る |
| 外回りの点検 | 屋根や雨どい、外壁、塀、窓ガラスに傷みがないか見る |
| 郵便 | 郵便受けを空にし、大事な郵便は持ち帰る |
| 庭 | 草や庭木の伸び具合、隣の家や道路にはみ出していないかを見る |
| 戸締まり | 窓・勝手口・物置の鍵を確かめ、雨戸の開け閉めを決めておく |
| 記録 | 気になった所を写真に撮り、日付と一緒に家族で共有する |

見回りの間隔は、家の傷み具合や季節、通える距離によって変わります。間隔を決めるときは、梅雨の時期や台風・大雪のあとなど、**傷みが出やすいときに臨時で見に行く**ことも一緒に決めておくと安心です。

## 電気・水道・ガスを止めるか残すか

| 契約 | 残すと | 止めると |
|---|---|---|
| 電気 | 見回りのときに照明や掃除機が使える。防犯用の照明も付けられる | 基本料金はかからないが、見回りの作業がしにくい |
| 水道 | 通水や掃除ができる | 排水口の水が切れやすくなり、においの原因になることがある |
| ガス | 使う予定がなければ、残しておく理由は少ない | 使わないなら止めておくと安心という考え方もある |

どれを残すかは、見回りの頻度や、片付け・売却の予定によって変わります。冬に冷え込む地域では、水道管の凍結への備えも必要です。凍結の防ぎ方は、地域の水道局の案内を確認してください。

また、火災保険は、住む人がいなくなったことで扱いが変わる場合があります。空き家になったことを保険会社や代理店に伝え、今の契約で補償されるかを確認しておきましょう。

## 遠方で通えないときの頼み先

| 頼み先 | 向いている場合 | 気をつけたいこと |
|---|---|---|
| 家族が交代で通う | 片道の移動が負担にならない | 一人に偏らないよう、順番と費用の分け方を決める |
| 親戚・近所の人 | 実家の近くに頼れる人がいる | 頼める範囲を具体的に伝え、お礼の形を考えておく |
| 空き家の管理サービス | 定期的に通うのが難しい | 作業の範囲と報告のしかた、鍵の預け方を確かめる |
| 地域の団体(シルバー人材センターなど) | 庭の手入れや簡単な見回りを頼みたい | 地域によって、受けている仕事の内容が違う |

鍵の受け渡しや、写真での報告の受け方は、[遠方の実家を片付けるとき]({{ '/posts/enpou-jikka-katazuke/' | url }})の段取りも参考になります。

### 管理が行き届かないときの扱い

空家等対策の推進に関する特別措置法により、管理が十分でない空き家については、自治体から助言や指導を受けることがあります。制度の概要は[国土交通省](https://www.mlit.go.jp/)のサイトで紹介されています。実家のある自治体の空き家の相談窓口では、管理や活用についての相談ができることもあるので、一度問い合わせてみるとよいでしょう。

## 依頼する前に確認したいこと

空き家の管理サービスに頼む場合は、申し込む前に次の点を確認しておきましょう。

- 1回の見回りで、どこまで作業してくれるか(換気・通水・郵便・庭・室内の掃除など)
- 見回りの間隔と、台風や大雪のあとに臨時で見てもらえるか
- 報告の方法(写真付きの報告書か、何を撮ってもらえるか)
- 鍵をどう預けるか、紛失したときの対応
- 傷みを見つけたとき、修理の手配までしてくれるか、その費用はどうなるか
- 料金に含まれる作業と、別料金になる作業
- 解約するときの手続きと、いつまでに伝える必要があるか

## よくある質問

### Q. 片付けが終わる前に空き家になりました。物はそのままでいいですか？

すぐに片付けられなくても、換気や通水は続けられます。ただし、生ものや食品、薬、現金や通帳などの貴重品は、早めに持ち帰るか処分しておくと安心です。片付けの順番は[実家の片付けは何から始める？]({{ '/posts/jikka-katazuke-nanikara/' | url }})で整理しています。

### Q. いつまで管理を続ければよいですか？

決まった期間はありませんが、管理には手間と費用がかかり続けます。「一周忌まで」「次の固定資産税の通知が来るまで」など、家の行き先を家族で話し合う時期を先に決めておくと、ずるずると先送りになりにくくなります。

## まとめ

空き家になった実家は、換気・通水・点検・郵便・庭・戸締まりの6つを、誰がどのくらいの間隔で見るかを決め、写真で記録を残しながら管理するのが続けやすい方法です。通えない場合は、親戚や管理サービスに頼る方法もあります。売る・貸す・残すなど、家の行き先の比べ方は[片付けたあとの実家をどうする？]({{ '/posts/katazuketa-jikka-dousuru/' | url }})にまとめています。
