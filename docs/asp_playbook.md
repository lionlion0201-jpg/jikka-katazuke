## 方針
- 収益の柱は業者紹介(見積もり・査定の申込み1件ごとの報酬)。Amazon は仕分け用品などの補助
- 案件リンクは **提携承認後** に記事へ入れる。承認前は一般名で書き、リンクは置かない
- 案件ごとの禁止キーワード・禁止表現(「最安」など)を必ず確認する
